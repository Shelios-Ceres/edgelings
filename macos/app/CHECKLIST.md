# Edgelings: two-minute checklist for a person

The part of the test that an agent running in Terminal cannot do: it needs eyes and a pointer. Answer each line with a word or two. If something looks wrong, a screenshot helps.

1. **The drawer.** Is there a column of round characters on the right edge of your main screen? How many? Does each match an agent you have (Claude, Codex, Antigravity, Grok, Kimi Code, DeepSeek)?
2. **The icon.** In Finder, in Spotlight (press Command-Space and type Edgelings) and in Settings > General > About: does Edgelings show a purple robot head on a cream rounded square, not a blank page? Spotlight should list **one** Edgelings, not two.
3. **Hover.** Rest the pointer on a character for a second. Does a card open with the agent's name, quota bars and token counts?
4. **Click.** Click a character. Does Settings open?
5. **Right-click.** Right-click a character. Does a menu open (Shown agents, Look, ...)?
6. **Drag.** Drag a character up or down. Does the whole column follow, then settle where you let go?
7. **Settings pages.** Open each page (Agents, Drawer, Usage & cost, General). Note anything cut off, overlapping or empty. Try both styles (Settings > Drawer > Character style) and, in Classic, Chinese.
8. **Dark mode.** Switch macOS to dark and back. Do the cards, the Settings window and the menu-bar icon follow?
9. **Awake and asleep.** Open and quit one agent's app (for example Kimi Code). Does its character wake and fall asleep with it?
10. **Working.** Start a long task in one agent. Does its character change while it works and say a short line when it finishes?
11. **CPU while calm.** With no agent working, open Activity Monitor, find Edgelings, and let it settle for a minute. Write down its % CPU, whether the Mac is on battery or plugged in, and the Mac's display (built-in or external).
12. **CPU while an agent works.** Start a long task in one agent and write down Edgelings' % CPU after a minute. Then open Settings > Drawer, set "Frame rate while an agent works" to 60 fps, switch "Save battery" on, and write it down again. (Calm characters always run at 30 fps; there is no 30 fps setting.)
13. **Kimi Work (only if you have the Kimi desktop client).** Start one Kimi Work task. While it runs, does the Kimi character work, and does it say "done" when the task finishes? Then switch the client to manual approval and give it a task that runs a command: while the client asks you to approve, does the Kimi character show a waiting-for-approval state and say so? (If it stays idle through the whole task, say so: the probe in PROBE.md section 7 finds where its data is on your Mac.)
14. **Copy diagnostic.** Settings > General > About > Copy diagnostic, and paste it into the report.
