# Edgelings roadmap

The roadmap is in [ROADMAP.md](../ROADMAP.md).

This file used to describe Agent Island 2.1.2 (the upstream project Edgelings grew out of): five providers, report cards and turn alarms on macOS and Windows, released from one tag. That is history now. The Windows app has since been rebuilt as a character drawer, and the macOS app is still 2.1.2 plus small fixes. See the [README](../README.md) for the current state and [CHANGELOG.md](../CHANGELOG.md) for upstream's release history.
